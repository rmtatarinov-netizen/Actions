# Тестовый FastAPI бэкэнд для получения текущего времени сервера

Простое приложение на FastAPI, возвращающее текущее время сервера.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск приложения

```bash
uvicorn main:app --reload
```

Приложение будет доступно по адресу: http://localhost:8000

## Эндпоинты

- `GET /` - приветственное сообщение
- `GET /time` - возвращает текущее время сервера
- `GET /date` - возвращает текущую дату сервера

### Пример ответа с `/time`

```json
{
  "current_time": "2026-10-17 12:34:56",
  "isoformat": "2026-10-17T12:34:56.123456",
  "timestamp": 1760689296.123456
}
```

### Пример ответа с `/date`

```json
{
  "current_date": "2026-10-23",
  "isoformat": "2026-10-23",
  "year": 2026,
  "month": 10,
  "day": 23,
  "weekday": "пятница"
}
```
